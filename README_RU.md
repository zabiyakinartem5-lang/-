# BLACK CLIENT — стартовый проект

Клиентский мод-основа для Minecraft Java 1.21.4 + Fabric. Это стартовый прототип: меню и экран внешнего вида включены, но конфигурация пока хранится только в памяти, а 3D-скин и музыкальный плеер ещё нужно подключить.

## Требования
- JDK 21
- IntelliJ IDEA Community
- Minecraft Java 1.21.4
- Fabric Loader и Fabric API для 1.21.4

## Запуск
1. Откройте папку проекта в IntelliJ IDEA как Gradle-проект.
2. Дождитесь синхронизации Gradle.
3. Запустите задачу `runClient`.
4. Для сборки выполните `gradlew.bat build` в Windows или `./gradlew build` в Linux/macOS.
5. Готовый JAR ищите в `build/libs/`; устанавливайте его в `mods` вместе с Fabric API.

## Что реализовано в прототипе
- замена главного экрана через Mixin;
- полностью монохромное оформление без короны и ярких цветных акцентов;
- стандартный шрифт Minecraft и кнопки, выровненные слева;
- процедурный тёмный фон с квадратной луной, силуэтами деревьев и лёгким движением бликов на воде;
- кнопки одиночной игры, мультиплеера, настроек, внешнего вида и выхода;
- лёгкие движущиеся фиолетовые частицы и пульсирующий заголовок;
- экран внешнего вида с выбором одной из четырёх тем и переключателями эффектов.

## Что доработать для полноценного релиза
- сохранять тему/частицы/упрощённую анимацию в JSON-файл в папке config;
- применять выбранный цвет ко всем кнопкам и панелям;
- использовать официальный рендеринг модели игрока для превью скина;
- добавить музыку как ресурс `assets/blackclient/sounds/` и зарегистрировать sound event;
- добавить ползунок громкости и кнопку mute;
- заменить простые частицы на фон-текстуру/шейдер только при включённом режиме качества;
- проверить Mixin и сборку именно на выбранных версиях Fabric Loader/API.

Если сборка не проходит, проверьте совместимость версий Loom, Yarn, Loader и Fabric API для 1.21.4. Версии в Gradle-файлах — стартовые и могут потребовать обновления под текущий репозиторий Fabric.
